# Community launch kit — Caelestia WebApps 0.4.1

These texts are prepared for publication after the final checklist below is
complete. Caelestia WebApps is always described as an unofficial community
project.

## Final checklist

- [ ] AUR page `https://aur.archlinux.org/packages/caelestia-webapps` exists.
- [ ] `yay -S caelestia-webapps` succeeds on the real validation host.
- [ ] README says that the AUR package is live instead of being prepared.
- [ ] GitHub `main`, latest release and README changes are synchronized.
- [ ] Both screenshots render on the public GitHub page.
- [ ] No profile, cookie, token, log or private desktop content is attached.

Do not paste the AUR command into a public announcement until the first two
items pass.

## Caelestia GitHub — Show and tell

Title:

> Caelestia WebApps — an unofficial Firefox WebApp manager for Caelestia and Hyprland

Body:

> Hi! I built **Caelestia WebApps**, an unofficial community project for
> installing and managing isolated Firefox-based WebApps on Hyprland.
>
> The standalone Quickshell manager follows the navigation, motion, palette and
> grouped settings style of Caelestia's Nexus UI. It includes a built-in and
> user-defined WebApp catalog, per-app Firefox profiles, install/repair/remove
> actions, optional TopBar applets and German/English localization.
>
> The integration deliberately stays outside private Caelestia QML APIs. On
> current Hyprland Lua configurations, app rules are applied without a complete
> monitor reload.
>
> Install on Arch/CachyOS: `yay -S caelestia-webapps`
>
> Repository and screenshots:
> https://github.com/psdl76/caelestia-shell-installer
>
> Release 0.4.1:
> https://github.com/psdl76/caelestia-shell-installer/releases/tag/v0.4.1
>
> Feedback about the workflow, UI consistency and useful WebApps is welcome.
> This is not an official Caelestia component and is not maintained by the
> Caelestia team.

## Hyprland community

> I released **Caelestia WebApps 0.4.1**, an unofficial standalone Quickshell
> manager for isolated Firefox WebApps on Hyprland. It manages desktop entries,
> profiles and app-owned window rules, and current Hyprland Lua sessions receive
> targeted runtime-rule updates without a full monitor reload. The interface is
> inspired by Caelestia Nexus but does not import private Caelestia APIs.
>
> Arch/CachyOS: `yay -S caelestia-webapps`
>
> Screenshots, source and release:
> https://github.com/psdl76/caelestia-shell-installer
