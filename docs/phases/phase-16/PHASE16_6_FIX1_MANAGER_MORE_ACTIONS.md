# Phase 16.6 fix1 — Manager More Actions

The Phase 16.6 capability runtime remains unchanged. This fix only reduces Manager action clutter.

- Installed cards keep the primary Open/Focus action and the Applet on/off toggle visible.
- Secondary actions move behind one `…` button.
- The modal uses the existing Caelestia Manager design tokens and gives every action a short explanation.
- Applet settings and Firefox profile/setup are no longer represented by two identical gear icons.
- User WebApp edit/remove actions use the same dialog when applicable.
- Existing manager functions and stable CLI commands remain the execution path; no new runtime API is introduced.
