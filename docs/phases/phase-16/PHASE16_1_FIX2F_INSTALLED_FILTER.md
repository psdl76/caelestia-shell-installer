# Phase 16.1-fix2f – Installed Filter

Status: candidate for live acceptance.

The installed-count indicator in the manager is now interactive. Clicking `X installiert` switches the list to a synthetic `installed` filter and shows only installed WebApps. Search continues to work inside that filter. Selecting Featured, All, or any normal category leaves the installed filter again.

The control reuses the existing category-pill theme tokens so it stays visually aligned with the Caelestia-style category strip.
