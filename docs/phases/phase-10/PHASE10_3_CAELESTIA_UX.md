# Phase 10.3 – manager-caelestia-ux-01

Project-owned Caelestia-like UI primitives now sit on top of the real dynamic Material-You palette.

- `ActionButton.qml`, `IconButton.qml`, `SearchField.qml`
- Material Symbols for primary and secondary actions
- compact icon actions + tooltips for Setup/Repair/Edit/Delete
- short press morph on buttons, categories and switch
- search focus ring, material icon and inline clear
- slightly roomier app rows
- wizard and destructive dialog share the same action language
- no private Caelestia Shell QML imports
- backend/CLI/runtime/ownership semantics unchanged
