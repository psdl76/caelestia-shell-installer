# Caelestia Motion Pass — v0.3.27

UX correction after live testing.

- Status feedback is now a true in-window overlay anchored 20 px above the manager's
  bottom edge. It no longer participates in ColumnLayout and cannot be pushed/clipped
  outside the window by the app grid.
- Card morphing is intentionally more visible: corner deformation 24→36 px and a
  slightly stronger spatial lift.
- Icon surfaces now physically grow 58→66 px and become rounder while the card is
  hovered.
- Primary action buttons morph more clearly on hover/press.
- Backend action routes remain unchanged.
